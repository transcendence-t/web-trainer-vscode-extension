# 课程参考资料与许可

课程讲解、示例、场景素材、起始代码、参考答案和判题规则均为本项目原创。下列资料用于核对知识范围、教学顺序和验证方法。仓库代码许可与教材内容授权分别核对。

| --- | --- | --- |

| MDN Learn Web Development | 核对语义 HTML、原生控件、CSS 样式与布局、JavaScript 和浏览器 API 的进阶顺序。参考技能小测和跨知识点挑战的粒度。 [MDN 核心学习模块](https://developer.mozilla.org/zh-CN/docs/Learn_web_development/Core) | 文档通常为 CC BY-SA 2.5 或更新版本，代码示例依其发布条款。 [MDN 署名与许可](https://developer.mozilla.org/en-US/docs/MDN/Writing_guidelines/Attrib_copyright_license) |
